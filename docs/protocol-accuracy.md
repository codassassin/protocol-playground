# Protocol accuracy and references

The walkthroughs are simplified teaching aids and may not cover every protocol variant, extension, edge case or deployment practice.

## Review guidance
Review message order and direction, state transitions, field semantics, timers/retries/caching, error behavior, security and version relevance, and stated simplifications. Report a specific step and cite a reliable source where possible.

## Starting points
These are starting points, not exhaustive references:
- TCP — RFC 9293: https://www.rfc-editor.org/rfc/rfc9293
- UDP — RFC 768: https://www.rfc-editor.org/rfc/rfc768
- DNS — RFC 1034 and RFC 1035, plus updates: https://www.rfc-editor.org/
- IPv4 — RFC 791 and updates: https://www.rfc-editor.org/
- DHCP — RFC 2131: https://www.rfc-editor.org/rfc/rfc2131
- BGP — RFC 4271: https://www.rfc-editor.org/rfc/rfc4271
- OSPFv2 — RFC 2328: https://www.rfc-editor.org/rfc/rfc2328
- TLS 1.3 — RFC 8446: https://www.rfc-editor.org/rfc/rfc8446
- QUIC — RFC 9000: https://www.rfc-editor.org/rfc/rfc9000

Use the RFC Editor and protocol maintainers' documentation for current specifications and updates. A citation should support the particular claim; citation presence alone does not prove a lab accurate.
