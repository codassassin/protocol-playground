# Feedback and Contributions to Packet City

Packet City is a proprietary project. **Code contributions and pull requests that add, modify, or redistribute project code are not accepted unless the copyright holder has explicitly authorized them in writing.**

Feedback, protocol-accuracy reports, issue reports, suggestions, accessibility observations, and documentation corrections that do not reproduce or distribute proprietary code are welcome.

## Reporting protocol or simulation issues
Include the lab and step, current behavior, expected behavior, an authoritative reference or reproducible explanation, and screenshots/recordings for visual issues.

## Feedback
Open an issue to suggest a feature, report a bug, or discuss an improvement. Please do not paste substantial portions of the project's source code into issue reports or discussions.

## Accuracy
Packet City is an educational visual model, not a full protocol implementation. Distinguish protocol behavior from simplifications and use primary references.

## AI-assisted development
AI tools may be used by the project maintainer. The project welcomes thoughtful independent review and feedback.

Treat contributors respectfully. Critique ideas and implementation, not people. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
