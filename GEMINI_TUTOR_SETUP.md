# Packet City AI Tutor — Bring Your Own Gemini API Key

The tutor uses a visitor-supplied Gemini API key. Packet City does not operate a shared API key or proxy.

## Connect
1. Create a key in Google AI Studio: https://aistudio.google.com/app/apikey
2. Open Packet City and open Network Tutor.
3. Paste your key and choose Connect & Start Learning.

The key is saved in the browser's local storage and sent from that browser directly to Google's Gemini API for requests. You can change or remove it from the tutor interface. Avoid keys you don't want stored in this browser. Gemini quotas, models and pricing/free-tier eligibility are controlled by Google and may change.

The tutor includes an instruction-based networking-only scope; this is not a hard guarantee against off-topic output.
